# Intégration API

Responsable : Jonathan Kakesa.

Cette mission ne crée aucun appel métier, compte utilisateur, paiement ou examen. Le catalogue utilise des données fictives explicites et des états React locaux ; aucune saisie n’est persistée. Le backend Django initial demeure inchangé. Voir API.md pour le contrat existant.

Avant une intégration : définir les types du contrat, les états de chargement/erreur, les délais et annulations, puis vérifier authentification, droits, CSRF et validation côté serveur. Ne jamais exposer de clé privée au navigateur. Les scores de démonstration ne doivent pas être présentés comme une estimation TCF réelle.
