Question proposée : Pourquoi les voyageurs doivent-ils changer de quai ?

- A. Des travaux empêchent l’accès habituel.
- B. Le train est annulé.
- C. Les billets doivent être échangés.
- D. Le départ est avancé.

Réponse proposée : A. Le document mentionne les travaux et précise que l’heure de départ ne change pas. Relecture humaine requise ; cette clé proposée n’est pas une validation pédagogique.
