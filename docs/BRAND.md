## Ligne éditoriale

- Promesse : **« La maîtrise du français, intelligemment. »**
- Ton : rassurant, professionnel, ambitieux, précis.
- Interface : cartes arrondies, animations discrètes, gradients maîtrisés, excellent contraste.
- Accessibilité : navigation clavier, responsive, `prefers-reduced-motion`.
- Typographie : Inter / Plus Jakarta Sans, suivant les licences et disponibilités.
