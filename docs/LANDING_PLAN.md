# Plan de l’accueil immersif

Responsable : Jonathan Kakesa.

1. Socle livré dans la mission : promesse, logo officiel, quatre compétences, approche et lien vers le catalogue ; affichage clair/sombre et responsive.
2. Validation visuelle et éditoriale : confirmer la direction, les déclinaisons du logo et le positionnement TCF Québec/Canada avec le responsable produit.
3. Définir les parcours réels et contrats API avant d’ajouter inscription, diagnostic ou entraînement.
4. Ajouter des interactions vocales utiles seulement quand l’enregistrement, les consentements et les états d’erreur sont spécifiés.
5. Mesurer les performances sur mobile réel avant d’envisager parallaxe ou 3D. Préserver une expérience statique équivalente.
6. Valider clavier, lecteur d’écran, contraste, contenus et métriques de performance avant promotion vers `tests`.

Aucune étape suivante ne déclenche une mise en production automatique.
