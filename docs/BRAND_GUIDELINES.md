# Identité Fluentia

Responsable : Jonathan Kakesa. Palette de référence : bleu nuit #081B35, bleu électrique #1769E0, cyan #21D4F4, blanc cassé #F7FAFF, bleu très sombre #061B3D.

Utiliser les logos PNG officiels du pack fourni, avec leurs proportions, sans flèche ajoutée ni symbole de remplacement. Le composant Logo sélectionne les versions horizontales selon le thème. Le symbole transparent fourni est décoratif dans la vitrine, avec texte alternatif vide.

Le slogan « Maîtrisez le français, allez plus loin. » est centralisé dans `lib/brand.ts`. La typographie UI est Poppins. Le logo lui-même n’est pas recomposé avec une nouvelle police. L’archive d’origine reste hors dépôt ; ses ressources graphiques et sa documentation source sont conservées dans `public/branding`.

Les valeurs chromatiques du pack diffèrent légèrement des tokens du brief. Ne pas recolorer les assets pour masquer cette différence. Les fichiers SVG fournis sont des reconstructions éditables, selon le README source ; ils ne constituent pas des masters certifiés. Les variantes PNG officielles sont utilisées à l’écran.
